# File Operations in Java

## 📌 Description
This Java program demonstrates how to perform basic file operations such as:
- Creating a text file
- Writing data into a file
- Reading data from a file
- Modifying (appending) existing file content

The program uses Java's built-in I/O classes and is suitable for beginners learning file handling.

## 🛠 Technologies Used
- Java (JDK 8 or above)
- FileWriter
- BufferedReader
- BufferedWriter
- FileReader

## 📂 Files
- FileOperationsDemo.java

## ▶️ How to Run
1. Compile the program:
javac FileOperationsDemo.java
2. Run the program:
java FileOperationsDemo

## 📌 Output
- Creates a text file
- Writes content to the file
- Reads and displays file content
- Appends new data successfully

## 📚 Use Case
Useful for understanding file handling concepts in Java such as reading, writing, and modifying files.
